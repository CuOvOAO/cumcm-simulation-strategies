# 实验规范

1. 全部方案使用同一批案例文件及模拟器版本；CSV自动记录案例SHA256。
2. 每个策略保留相同run(api, seed=0)接口，seed只控制策略内部随机性。
3. A/B/C结果分别输出results/A、results/B、results/C_seed1等，不互相覆盖。
4. 完成率不足1的案例必须展示，不能通过筛掉失败案例掩盖问题。
5. 对双方都全部清除的同案例做时间配对比较，并同时报告全部案例完成率。
6. C使用多个策略种子，报告均值、离散程度和最差表现；调参集与最终评估集分开。
7. 消融实验分别去掉B的主动补测、最近可靠清除点、多目标排序。
8. 自建1米网格固定误差是测试假设，不能声称官方同样实现；后续加入不同误差模型。
9. experiments/提交小型汇总与实验说明，写明代码commit、命令、案例与种子。
10. 模拟器接口单元测试由CI运行；正式模拟器日志仍按比赛要求原名保存。
