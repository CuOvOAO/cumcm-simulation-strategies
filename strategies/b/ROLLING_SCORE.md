# Plan B 候选评分与单步选择

`rolling_score.score_candidates(current_position, candidates, tracker)` 返回按优先级
排序的不可变 `ScoredAction` 元组，保留候选、总分、全部分项、情景数量和认证标志。
`select_action(...)` 返回首个 `CandidateAction`，空候选返回 `None`。
支持同批多个频道，每个候选只查询本频道公开历史与保守区域；不修改 tracker。
仅对传入候选评分，不补造动作，不调用 API，也未接入 `strategies/b/main.py`。
可将已有 `generate_candidates` 的输出传入；多个频道的候选可合并后选择一步。

## 公式与集中参数

measure 分数越大越优：

`S = (1 - R) * (4 G + 2 A + 2 Q) - D - 5 R`

所有权重集中在 `rolling_score.py` 的不可变 `ScoreWeights` / `WEIGHTS`：

| 分项 | 权重 | 定义 |
| --- | ---: | --- |
| G 缩域代理 | 4.0 | 固定情景中，可被一次测量区分的有序点对占全部 n² 点对的比例 |
| A 交会角 | 2.0 | 各情景相对历史测向位置的最大绝对交会角正弦，按情景平均 |
| D 移动代价 | 1.0 | 当前位置到候选的欧氏距离 / 1000 米 |
| R 重复风险 | 5.0 | 同频道历史中最大位置重复风险，且同时衰减所有收益 |
| Q 重捕获 | 2.0 | 无历史或最新反馈为 no_signal 时，距离候选不超过公开最小接收半径的情景比例；否则为 0 |

G、A、R、Q 均在 [0,1]；D 不截断。权重为人工初始设定，未用案例调参。
其他参数同样集中于模块顶部：`SAMPLE_INTERVALS=16`（每轴 17 点）、
`DISTANCE_SCALE_M=1000`、`REPEAT_SCALE_M=25`、公开接收上下界
`PUBLIC_MIN_RANGE_M=1000` / `PUBLIC_MAX_RANGE_M=1500`、`PUBLIC_NEAR_M=5`。
方向半宽从 region 导入 `BEARING_HALF_WIDTH_DEG=1.005`，不另行配置。
距离项是归一化距离，不是秒数；未建模换频道代价或预计总完成时间。

## 情景与分项计算

对本频道区域复用 safe-clear 的保守外包盒，在各轴等分 16 段，包含端点，
构造最多 289 个不同格点；排序后只保留通过完整 `region.contains` 的点。
每次评分每频道只构造一次。没有采样点时 G、A、Q 取零，继续使用距离与重复代价；
这不证明可行域为空，也不触发清除。

G 的计算不假定实际接收半径或未来测向误差。情景 p、q 在候选位置共享以下任一
可能反馈时，视为不可区分：两者距离都 ≤5（near）；都 ≥1000（no_signal，
保守保留边界）；或都在 (5,1500] 且方位差的最小绝对值 ≤2×1.005°（direction）。
1000—1500 米不确定带允许方向和无信号两种反馈。用全部无序点对中无共同反馈
的数量 k 计算 `G=2k/n²`，等价于等权情景下可排除比例的保守代理；不是实际面积
缩减期望，不把等权格点解释为后验均匀分布。n=1 时 G=0。

A 对情景 q，仅在候选距 q 属于 (5,1000] 时计算；否则贡献零。
以 q 为顶点，比较候选位置与各个不同历史 direction 位置的射线，取
`max |sin(angle)|`。退化零长度历史射线跳过；无历史方向贡献零。
因此垂直交会贡献最大，共线及反向共线贡献零；历史重复不会累加角度收益。
该项衡量相对已有测向的几何补充，不是已有定位精度的严格增量。

R 对每条本频道历史观测，不区分反馈类型：与候选同 `(floor(x),floor(y))`
网格时风险为 1，否则为 `max(0,1-distance/25)`；取全部历史最大值。
同网格收益完全归零，并扣除 5 分。25 米衰减是主动避开邻近重复的启发式，
不声称官方误差相关尺度为 1 米或 25 米。已有生成器排除同网格，但评分接口
也能处理外部传入的重复候选。

## clear 与确定性

clear 必须针对候选实际坐标重新调用 `reliable_clear_point(region, point)`；
不信任 reason 中的认证标签，未认证抛出 ValueError。认证 clear 在排序的第一层
无条件优先于所有 measure，不用有限加分模拟优先级。多个认证 clear 按距离
最近者优先，展示分数为 `-D`，其他分项与情景数量置零。

同优先级按分数降序，再按频道、x、y、reason 升序打破平局，不依赖输入候选顺序。
使用固定格点，无随机数；相同环境和输入重复调用得到相同结果。
坐标须有限且各分量绝对值 ≤2,000,000，频道须为 1—20 整数，动作须为 measure/clear，
非法输入抛出 ValueError；不会静默跳过非法 clear。

## 验证和局限

新增 `test_b_rolling_score.py` 使用手工公开反馈，覆盖 clear 绝对优先、多个 clear、
伪造认证拒绝、距离代价、等距离侧向补测、重复/邻近测量、多频道隔离、
输入乱序确定性、不修改状态、平局、空候选、空情景、重捕获、公式及输入校验。
验证命令：`python -m unittest -v` 和 `git diff --check`。

评分与新增测试不读取 cases、目标真值、实际接收半径、误差种子或模拟器内部状态。
全套测试包含仓库原有模拟器测试，不能把其通过解释为策略性能验证。
本模块仅依赖标准库，语法兼容 Python 3.10。

有限格点可能漏掉细窄、非凸区域，采样权重也可能失真。G 不模拟连续反馈概率，
A 不保证补测能带来实际改进，Q 不是真实重捕获概率。不存在严格最坏情况保证、
全局最优或完成清除保证；safe-clear 证明独立于情景评分，沿用其现有模型局限。
计算量每频道候选约 O(n² + n h)，区域采样另需 O(289 h)，h 为历史长度；
尚未进行长历史性能实验。复用私有外包盒和网格辅助函数，接口变更需同步维护。
尚未实现多步前瞻、动作执行、清除后频道生命周期或完整 B 策略。
